# Research & Prototyping Notebooks

Esta pasta contém notebooks Jupyter utilizados para a fase de pesquisa, testes rápidos e prototipagem de algoritmos.

## Conteúdo
- **`people_counting.ipynb`**: Notebook principal para testes de detecção e Re-ID em ambiente interativo. Utiliza `ipywidgets` para exibição estável e permite visualização rápida dos hiperparâmetros (thresholds).

## Como usar
1. Certifique-se de que o ambiente virtual está ativo.
2. Instale `ipykernel` e `ipywidgets`.
3. Abra o notebook em seu editor (VS Code, JupyterLab, etc.).

> [!NOTE]
> Para execução em produção ou performance máxima, utilize o código modularizado na pasta `src/` na raiz do projeto.
